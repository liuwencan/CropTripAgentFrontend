# 约束输入：规范遵循与一致性

> 决策点索引：三种约束模式（遵循规范/保持一致性/无约束）、仲裁规则、样式系统识别、扫描隐私。🟡 启发级（仲裁本身为硬规则）。

## 三种约束模式（按优先级仲裁）

| 模式 | 用户输入 | 技能行为 |
|---|---|---|
| 遵循规范 | "按 Material Design / AntD / 自家设计系统 / 某文档" | 以规范为准：颜色/间距/组件用法读规范原文；规范与通用规则冲突时**规范优先** |
| 保持一致性 | "新页面要和旧页面风格一致" | 扫描旧页面**只提取设计 token**（色板/圆角/间距/字号）+ **识别组件库与变体清单**（Element Plus 还是自研、用哪种按钮变体），作为约束；**不学习**旧页面的结构/组件用法/状态处理（防污染）；token 提取结果做 sanity check（如全白/空值视为失败） |
| 样式系统 | 识别落地方式：Tailwind / SCSS / CSS-in-JS / 组件库主题——同一 token 四种落法不同；一致性扫描同时识别样式系统 |
| 无约束 | 未指定 | 用通用决策表；首次为新页面建立 token 基线 |

## 仲裁规则

**规范 > 一致性 > 通用**。一致性 token 提取失败（无旧页面/无设计系统/提取结果异常）时回退通用规则。约束模式未明确时，按 SKILL.md §0.5 带选项询问。

**隐私**：一致性扫描读旧页面源码时，发现的敏感数据（密钥/用户数据/密码）**不写入技能输出或记忆**。

**仲裁示例**：规范要求圆角 8px、旧页面是 4px → 用户选"遵循规范"用 8px；选"保持一致"用 4px；未明确 → 问用户。组件库冲突（规范用 A 库、旧页用 B 库）同理仲裁。
