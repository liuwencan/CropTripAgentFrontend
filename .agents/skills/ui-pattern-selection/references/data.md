# 数据展示：图表 / 表格 / 列表 / 树 / 标签

> 决策点索引：图表 11 种选型、表格 vs 列表 vs 卡片、表格内部细节、树/标签/徽标/描述列表、默认视图。均为 🟡 启发级。

## 图表选型

| 意图 | 图表 | 坑 |
|---|---|---|
| 看趋势 | 折线图 | 别用平滑曲线伪装精确度；多条线 ≤5 |
| 比类别 | 柱状图 | 类别多（>10）转横向 |
| 做排名 | 横向条形图 | 按数值降序 |
| 看占比/结构 | 饼图 | 类别 ≤5（NN/g 建议），>5 用条形/堆叠；别 3D 饼图 |
| 两变量关系 | 散点图 | 加密度/回归线辅助；大数据降采样 |
| 趋势+强调总量 | 面积图 | 多系列堆叠注意可读性 |
| 转化/流失 | 漏斗图 | 各阶段真实数值 |
| 类别拆构成 | 堆叠柱状图 | 堆叠层 ≤5；颜色语义统一 |
| 二维交叉规律 | 热力图 | 色阶有图例；离散值别用连续色阶 |
| 多项能力打分 | 雷达图 | 维度 ≤8；数值差异小则雷达无意义（改条形） |
| 单 KPI 数值 | 大数字组件（别上图） | 一个数就是图表的滥用 |

**补充规则**：数据量级大（万级以上）→ 降采样/聚合后再画；图表空数据 → 显示空状态而非空白画布；状态色（成功/警告/危险）用色盲安全配色（不只靠红绿）；**图表提供导出/下载**（有数据导出需求时）。

## 表格 / 列表 / 树 / 标签

| 场景 | 规则 |
|---|---|
| 表格 vs 列表 vs 卡片 | 需排序/筛选/对比/多列→表格；信息少要视觉→卡片网格；纵向浏览→列表 |
| 表格内部 | 列多→横向滚动+固定关键列；行内操作 ≤2→操作列直接放，多→Dropdown；层级数据→树形表格；排序/筛选放表头；批量操作 → 选中后出现操作条；**编辑方式：单字段快速改→行内编辑；多字段→弹窗/抽屉编辑** |
| 树 Tree | 层级浏览；勾选/拖拽按需；层级 ≤2 用缩进列表 |
| 标签 Tag | 状态用彩色 Tag（成功绿/警告橙/危险红） |
| 徽标 Badge | 数量/未读→红点+数字 |
| 描述列表 | 键值对详情→Descriptions，别用表格硬套 |
| 默认视图 | 给默认排序/默认筛选（服务端有默认参数时跟随）；用户调整后持久化 |
