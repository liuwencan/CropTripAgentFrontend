# 反馈：弹窗 / 操作提示

> 决策点索引：弹窗 3 种（Modal/Drawer/Popover）、操作提示（Toast/Notification）、破坏性操作三模式、成功反馈级别。均为 🟡 启发级。

## 弹窗

| 类型 | 使用场景 | 坑 |
|---|---|---|
| 居中弹窗 Modal | 确认/短表单/必须阻断 | 焦点进入+关闭归还；ESC 关闭；**禁止业务弹窗套业务弹窗**；模态内 confirm 用覆盖层（非嵌套）或按钮内确认/undo |
| 侧边抽屉 Drawer | 大内容/长表单/保留上下文 | 宽度 ≤ 视口 50% |
| 气泡 Popover | 轻量内容（说明/小表单/预览） | 不承载复杂交互 |

## 操作提示

| 类型 | 使用场景 | 坑 |
|---|---|---|
| Toast | 2~5s 自动消失、不打断、单一信息 | 底部/顶部，别居中 |
| Notification | 需稍后处理/可操作/信息量大 | 右上角，可停留 |
| **破坏性操作三模式** | ① 不可逆/高风险（删数据）→ **confirm 弹窗**，写清后果；② 可撤销 → **undo toast**（Gmail 式，比弹窗轻）；③ 低风险可逆（改设置）→ **直接执行+操作日志** | 按可逆性选，别一律弹窗 |
| 成功反馈级别 | 破坏性/低频操作成功 → **必须提示**；常规提交 → 提示；高频无感操作（自动保存/点赞/已读）→ **静默**或极轻反馈 |
