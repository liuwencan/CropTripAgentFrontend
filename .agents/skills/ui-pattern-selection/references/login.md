# 登录页：布局形态 × 认证方式

> 决策点索引：登录布局 5 式、认证方式 6 种、注册入口、记住我/自动登录。均为 🟡 启发级。

## 布局形态

| 布局 | 使用场景 | 坑 |
|---|---|---|
| 居中卡片式 | 工具类/后台/SaaS 默认；专注单一任务 | 卡片内别塞多余装饰 |
| 左右分屏式 | 品牌展示型产品（左卖点/产品图/数据，右表单） | 左侧要有真实价值内容，别纯色块 |
| 沉浸背景式 | 品牌氛围强/活动类 | 表单卡片保证对比度可读（玻璃效果见 visual.md） |
| 多角色 Tab 登录 | 平台型（用户/商家/管理员） | Tab ≤3；明确默认角色 |
| 分步登录 | 手机号→验证码→（补全资料）；移动端优先 | 每步一个主操作；可回退 |

## 认证方式（社区推荐）

| 方式 | 使用场景 | 推荐要点 |
|---|---|---|
| 账号+密码 | 通用基线；B 端/工具默认 | 密码可见切换；行内校验 |
| 手机验证码 OTP | 国内 C 端主流（免密码低门槛） | 60s 重发倒计时；自动填充 |
| 扫码登录 | 桌面 Web 跨端（微信/钉钉/App 扫码） | 登录态同步；二维码过期刷新 |
| 第三方登录 | 降低摩擦（微信/Google/GitHub） | **次要样式放密码下方**，不是替代品 |
| SSO/企业登录 | 企业内部/团队工具 | 跳转 IdP；回跳处理 |
| 无密码魔法链接 | 开发者工具/极简产品 | 邮件即登录；适合低频工具 |

**社区共识**：登录页保持简单——单一主操作、社交登录是次要选项、移动端优先 OTP、桌面优先扫码、别隐藏注册入口。布局形态与认证方式**两维正交组合**（如：分屏布局 + 密码为主 + 扫码为辅）。

## 注册入口与记住我

- **注册入口**：与登录同层级可见（登录页/顶栏"注册"）；可独立页或同页切换；有第三方登录时注册可缩短（一键授权）。
- **记住我/自动登录**："记住我"持久化登录态（非敏感环境）；自动登录需明确告知用户（避免未经同意保持登录）。
