# 页面结构：官网首页 / 首屏 / 导航

> 决策点索引：官网首页 10 区结构、首屏 3 式（含何时不做 hero）、导航 9 种。均为 🟡 启发级。

## 官网首页 10 区

| 区域 | 规则 |
|---|---|
| 导航栏 | 见下方导航选型 |
| 首屏 Hero | 见首屏 3 式 |
| 价值主张 | 3 句话讲清：给谁用 → 解决什么 → 凭什么信；配真实截图/插画，禁止纯文字墙 |
| 信任条 | 客户 logo / 用户数 / 评分 / 奖项；必须真实，宁缺毋滥 |
| 功能区 | 3~6 个功能卡片；每卡=图标+标题+一句说明；可点击进详情 |
| 用户评价 | 3~6 条；真实头像+姓名+职位+原话；网格或轮播 |
| 价格表 | 2~4 档；中间档高亮+"推荐"标记；功能/配额对比清晰；每档一个行动按钮 |
| FAQ | 手风琴；5~10 问；按真实疑问组织；短答+详情链接 |
| 行动按钮 CTA | 全页 3~5 处重复（首屏 1 个主 CTA + 关键节点）；最终 CTA 用主操作样式 |
| 页脚 | 导航+联系+版权/备案+社交链接；订阅框（若有） |

规则：10 区按产品类型裁剪，顺序可调，但 Hero→价值→功能→证据→行动的主线不变。

## 首屏 Hero 3 式

| 类型 | 规则 |
|---|---|
| 产品介绍类 | 先讲清帮谁解决什么问题 → 展示产品（截图/演示）→ 信任证明（数据/评价）→ 行动入口 |
| 个人品牌形象类 | 先展示定位（我是谁/做什么）→ 代表作 → 风格 |
| 活动行为召唤类 | 先说清主题/时间点/参与价值 → 唯一行动入口 |

总规则：首屏不是塞满内容，而是先回答用户需求；主 CTA 唯一、明显。**何时不做 hero**（⚪）：工具类/后台/数据密集型产品 → 直入功能或仪表盘。

## 导航 9 种

| 类型 | 使用场景 | 坑 |
|---|---|---|
| 悬浮吸顶 Sticky | 长滚动页面需随时可达；营销页/文档站 | 别太高压内容；backdrop-filter 注意性能 |
| 侧边栏 Sidebar | 后台/多层级内容/工具类 | 可折叠；折叠态只留图标+tooltip；当前项高亮 |
| 面包屑 Breadcrumb | 层级 ≥3 且需定位/回退 | 层级 ≤2 别加（噪音） |
| 二级下拉子菜单 | 顶级栏目 ≤7 且每项有子项 | 悬停展开要延迟+防误触；移动端必须点击展开 |
| 巨型菜单 Mega Menu | 子项多（>8）且可分类/带描述/配图；电商/大站 | 别塞全站地图；保持 1 屏内 |
| 汉堡抽屉 | 移动端默认；桌面内容多时也可 | 遮罩+点击关闭+焦点管理 |
| 全屏遮罩 | 沉浸式导航/站点地图/极简大站 | 打开必须有明显关闭方式（ESC+X） |
| 锚点导航 | 单页长内容 | 滚动联动高亮；平滑滚动 |
| 滚动收缩 | 吸顶基础上省空间 | 收缩别只剩 logo |
