# 路由与权限

> 决策点索引：路由结构、路由守卫、404 兜底、权限层级（隐藏 vs 禁用）、权限映射、安全要点。🟡 启发级；"前端权限必须后端兜底"为 🔴。

| 场景 | 规则 |
|---|---|
| 路由结构 | 静态 vs 动态（后端菜单）；嵌套路由；**路由级懒加载**（code-split） |
| 路由守卫 | 未登录 → 登录页；角色/权限守卫；登录后回跳原页面；**权限刷新时机**（角色变更/重新登录后重建动态路由与菜单） |
| 404 兜底 | 未匹配路由 → 404 页（非空白）；动态路由缺失 → 403/404 区分 |
| 权限层级 | 路由级（页面/菜单）+ 按钮级（自定义指令或函数式判断）+ 接口级；**无权限项处理：默认隐藏（防功能探测），高频/常用项改禁用+提示（诚实告知）** |
| 权限映射 | 菜单权限 ↔ 按钮权限 ↔ 接口权限保持一致（后端给权限点，前端只渲染） |
| **安全要点（🔴）** | **前端权限只是 UX 隐藏，真正的权限校验必须后端**（前端可被绕过） |

**按钮级权限示例（通用写法）**：

```ts
// 自定义指令：无权限则移除按钮
app.directive('permission', {
  mounted(el, binding) {
    if (!hasPermission(binding.value)) el.parentNode?.removeChild(el)
  }
})
```

```vue
<button v-permission="'order:create'">新建订单</button>
```
