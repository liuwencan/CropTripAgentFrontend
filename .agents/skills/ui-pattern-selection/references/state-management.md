# 状态管理选型

> 决策点索引：状态层级（局部/props/composable/Pinia/路由参数）、服务端数据放置、持久化。🟡 启发级。

| 层级 | 何时用 |
|---|---|
| 组件局部 ref/computed | 单组件内状态 |
| props 提升 | 2~3 个兄弟组件共享 |
| composable 复用 | 逻辑跨组件复用（不共享响应式状态） |
| Pinia 全局 | 跨组件共享且多写（用户信息/购物车/主题） |
| 路由参数 | URL 可表达的状态（筛选/分页） |

**规则**：
- 服务端数据用请求缓存层（见 api.md），**别用 Pinia 硬存**（除非明确失效策略）。
- 跨会话持久化 → localStorage（非敏感）/ Pinia persist。
- 从最小层级开始，不够再升级（对应 SKILL.md §0.1 决策链）。
- 组件库状态（表格选中行/展开行）留在组件内部，不进全局 store。

**锚点**：从最小层级开始——宁可 props 多传两层，也别为小状态上全局 store；全局 store 只放"跨组件共享且多写"的状态。
