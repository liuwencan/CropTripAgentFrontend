# 主题与国际化

> 决策点索引：深色模式三态、品牌 token、i18n。🟡 启发级。

| 场景 | 规则 |
|---|---|
| 深色模式 | 语义 token + `prefers-color-scheme` + 手动切换 + 跟随系统三态；图片/阴影/logo 在深色下的处理；切换不闪烁；**对比度在深色下单独重验** |
| 品牌 token | 色板/圆角/间距/字号统一为 token 体系；组件用 token 不用裸值；深色模式提供 token 变体 |
| i18n | 文案外置；语言切换持久化；日期/数字/货币用 Intl 格式化；组件库语言包跟随；**文案长度容错**（中文→英文膨胀 30%+，布局要能容纳） |
