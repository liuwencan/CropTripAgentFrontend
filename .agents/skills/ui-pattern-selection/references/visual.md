# 视觉与双端：页面美化 / 双端适配

> 决策点索引：页面美化 7 种（🟡，液态玻璃 ⚪）、双端适配策略与规则（🟡）。骨架屏/空状态/懒加载见 SKILL.md §6.3/§8 与 guardrails.md，此处不重复。

## 页面美化

| 手法 | 使用场景 | 坑 |
|---|---|---|
| 页面留白 | 内容疏密度控制；营销/阅读页 | 数据密集页别过度留白 |
| 栅格 | 所有元素按隐形网格对齐（8px 基数） | 别用随机 px 值 |
| 卡片微交互 | 悬停抬升/阴影变化 | 动效 ≤200ms；别整页都动 |
| 瀑布流 | 图片流（高度不一）：作品集/商品图 | 懒加载+占位（见 guardrails.md）；移动端注意列数 |
| 液态玻璃 Glassmorphism | 时尚感/背景复杂场景（⚪ 可选） | 背景必须有内容；注意对比度/性能 |
| 语义色 | 成功/警告/危险色全站固定一套，不随场景乱换 | 与品牌 token 联动（见 theme-i18n.md） |

## 双端适配

**推荐策略**：双端可用（同一套代码响应式适配优先），仅在交互差异过大时拆独立移动布局。

| 维度 | 规则 |
|---|---|
| 断点 | 320 / 768 / 1024 / 1440 四档；移动优先书写 |
| 触控 | 触控目标 ≥44px（Apple）/48px（Material）**（含 padding 热区：文字按钮视觉可小但触控区达标）**；拇指热区（底部放主操作）；防误触（确认删除） |
| 安全区 | 刘海屏 safe-area-inset；横竖屏切换布局不变形 |
| 导航 | 桌面侧边栏/顶部 → 移动汉堡抽屉 |
| 表格 | 移动端横向滚动或卡片化（看列数决定） |
| 弹窗 | 移动端 Modal 全屏化或底部抽屉（BottomSheet） |
| 手势 | 移动端高频操作可用滑动（列表删除）——配确认或 undo；桌面端不用手势 |
| 表单 | 移动端单列、字段分组、提交按钮底部固定 |
| 性能 | 图片懒加载（见 guardrails.md）；减少动效 |
| 功能差异 | 移动端默认全功能适配（双端一致）；仅当交互确实无法承载时才降级/隐藏低频功能，**并告知用户**（渐进增强优先） |
